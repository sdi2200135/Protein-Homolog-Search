Remote Homolog Search

Εντοπισμός απομακρυσμένων ομόλογων πρωτεϊνών με συνδυασμό protein language models (ESM-2) και Approximate Nearest Neighbor αλγορίθμων.

Python 3.10+ PyTorch 2.0+ ESM-2 (fair-esm) BLAST ground truth

📖 Σχετικά με την Εργασία

Η παρούσα εργασία αποτελεί την 3η Προγραμματιστική Εργασία του μαθήματος «Ανάπτυξη Λογισμικού για Αλγοριθμικά Προβλήματα». Στόχος είναι η συγκριτική αξιολόγηση 5 προσεγγιστικών μεθόδων αναζήτησης πλησιέστερων γειτόνων για την ανίχνευση remote homologs — πρωτεϊνών με παρόμοια δομή/λειτουργία αλλά πολύ χαμηλή ομοιότητα ακολουθίας (< 30% identity).

🧬 ESM-2 Embeddings

Χρήση του protein language model ESM-2 της Meta για τη δημιουργία πυκνών διανυσματικών αναπαραστάσεων (320d) από ακολουθίες.

🔍 5 ANN Μέθοδοι

Euclidean LSH, Hypercube, IVF-Flat, IVF-PQ και Neural LSH — unified benchmarking στο ίδιο domain.

📊 BLAST ως Ground Truth

Τα αποτελέσματα του BLAST χρησιμοποιούνται ως reference για τον υπολογισμό Recall@N.

Καινοτομία: Η εργασία ενοποιεί όλες τις μεθόδους από τις 1η και 2η εργασίες (C++ και Python) σε ένα ενιαίο bioinformatics application με πραγματικά δεδομένα (SwissProt, UniProt).

🔀 Pipeline

Φάση 1 — Embedding Generation

FASTA → ESM-2 → Mean Pooling → 320d vectors → .dat file

Φάση 2 — BLAST Ground Truth

makeblastdb → blastp -outfmt 6 → blast_results.tsv

Φάση 3 — ANN Search & Evaluation

Load embeddings → 5 ANN methods → Recall@N vs BLAST → Report

ESM-2 Embedding Generation

Μετατροπή ακολουθιών πρωτεϊνών σε διανύσματα — protein_embed.py

1 Input

ΠαράμετροςΠεριγραφήDefault
-iInput FASTA file (π.χ. swissprot_50k.fasta)—
-oOutput binary filevectors.dat
--modelESM-2 variantesm2_t6_8M_UR50D
--batch-sizeBatch size8
--max-lengthMax sequence length1022
--devicecpu / cuda (auto)auto

2 Διαδικασία Embedding

  1. Φόρτωση FASTAΑνάγνωση με Bio.SeqIO.parse(). Φιλτράρισμα μη έγκυρων αμινοξέων (κρατάμε μόνο ACDEFGHIKLMNPQRSTVWY).
  2. Ταξινόμηση κατά μήκοςΓια βέλτιστο padding στα batches — μικρότερες ακολουθίες μαζί.
  3. Batch processingΟμαδοποίηση σε batches των 8. Κάθε batch περνά από τον batch_converter για tokenization.
  4. ESM-2 forward passmodel(tokens, repr_layers=[6]) → παίρνουμε representations από το τελευταίο layer (6ο για το 8M variant).
  5. Mean pooling με maskΑγνοούμε padding tokens μέσω mask. sum_embeddings / token_counts → ένα διάνυσμα 320d ανά πρωτεΐνη.
  6. Αποθήκευση σε binary fileCustom format: header "ESM2" + version + N + D + IDs + embeddings (float32).

Mean Pooling με Mask

mask = (tokens != padding_idx).float()
mask_expanded = mask.unsqueeze(-1).expand(token_embeddings.size())

sum_embeddings = torch.sum(token_embeddings * mask_expanded, dim=1)
token_counts = torch.sum(mask, dim=1, keepdim=True)
embeddings = sum_embeddings / token_counts.clamp(min=1e-9)
Γιατί mean pooling με mask: Αγνοεί τα padding tokens, δίνοντας ένα σταθερό 320d διάνυσμα που αντιπροσωπεύει ολόκληρη την ακολουθία.

3 Binary Format

# Δομή αρχείου vectors.dat
[4 bytes]  magic = "ESM2"
[1 byte]   version = 1
[4 bytes]  N = αριθμός πρωτεϊνών
[4 bytes]  D = διάσταση (320)
[4 bytes]  max_id_len

# IDs section
Για κάθε ID: [2 bytes length] + [UTF-8 string] + [padding]

# Embeddings section
N × D × 4 bytes (float32)
Πλεονέκτημα: Το binary format είναι 3x μικρότερο από CSV και η φόρτωση γίνεται με ένα np.fromfile() — στιγμιαία.

Euclidean LSH

Locality Sensitive Hashing με multi-probe — ANN/euclidean_lsh.py

1 Input

ΠαράμετροςΠεριγραφήDefault
--lsh_kΑριθμός hash functions ανά table10
--lsh_LΑριθμός hash tables5
--lsh_wΠλάτος παραθύρου4.0
seedSeed αναπαραγωγιμότητας42
probe_radiusHamming radius για multi-probe1

2 Build Phase

  1. initialize()Για κάθε table l ∈ [0, L): v_l (k×d, N(0,1)), t_l (k, U(0,w)). Δημιουργία defaultdict(list) hash tables.
  2. _hash(x, table_idx)Υπολογισμός floor((v·x + t) / w) → tuple από k ακέραιους.
  3. _build_tables()Για κάθε vector i: για κάθε table l: υπολογισμός hash, hash_tables[l][h].append(i).

3 Query Phase

  1. Ακριβές hashΥπολογισμός hash του query σε κάθε table.
  2. Multi-probe expansion_get_nearby_buckets(h, radius=1): παραγωγή όλων των hash codes με Hamming distance ≤ radius (αύξηση/μείωση κάθε συντεταγμένης κατά 1).
  3. Union candidatesΣυλλογή όλων των indices από τα buckets (set για deduplication).
  4. FallbackΑν len(candidates) < N*2: επέκταση σε όλα τα buckets των μισών tables.
  5. Sort & Top-NΥπολογισμός L2 αποστάσεων, sort, return top-N.

4 Μετρικές

  • Χρόνος αναζήτησηςΜέσος χρόνος ανά query σε δευτερόλεπτα.
  • QPSQueries per second (1 / time).
  • Recall@Nhits / min(N, |BLAST Top-N|) — υπολογίζεται vs BLAST ground truth.

Hypercube

Random projection σε δυαδικές κορυφές — Hypercube/hypercube.py

1 Input

ΠαράμετροςΠεριγραφήDefault
--hypercube_kBits του υπερκύβου10
--hypercube_MΜέγιστοι υποψήφιοι1000
--hypercube_probesΚορυφές προς εξέταση5
wΠλάτος παραθύρου4.0
seedSeed42

2 Build Phase

  1. __init__Δημιουργία v (k×d, N(0,1)), t (k, U(0,w)).
  2. _hash(x)tuple((floor((v·x + t) / w) % 2).astype(int)) → k-bit δυαδική κορυφή.
  3. _build_index()Για κάθε vector: cube[vertex].append(idx) — defaultdict(list).

3 Query Phase

  1. Hash queryΥπολογισμός query_vertex.
  2. Hamming vertices generator_hamming_vertices(vertex, max_vertices) — παραγωγή ίδιας κορυφής + όλων των 1-bit, 2-bit, ... διαφορών.
  3. Εξέταση κορυφώνΓια κάθε κοντινή κορυφή: αν υπάρχει στο cube, υπολογισμός L2 αποστάσεων για τα σημεία της.
  4. LimitsΣταματάει όταν checked ≥ M ή visited_vertices ≥ probes.
  5. FallbackΑν δεν βρέθηκαν candidates: brute force σε όλο το dataset.

4 Μετρικές

Ίδιες με LSH: Χρόνος, QPS, Recall@N vs BLAST.

IVF-Flat

k-means clustering + exact distances — IVFFlat/ivfflat.py

1 Input

ΠαράμετροςΠεριγραφήDefault
--ivfflat_nlistΑριθμός clusters100
--ivfflat_nprobeClusters προς εξέταση10
seedSeed42

2 Build Phase

  1. KMeans fitKMeans(n_clusters=nlist, n_init=10) — εκπαίδευση στα embeddings.
  2. cluster_assignmentsLabel κάθε vector (0..nlist-1).
  3. Inverted listsΓια κάθε cluster: λίστα από indices vectors που ανήκουν σε αυτό.

3 Query Phase

  1. find_nearest_centroidsΥπολογισμός L2 απόστασης query → κάθε centroid, sort, επιλογή nprobe.
  2. Union candidatesΣυλλογή όλων των vectors από τα nprobe clusters.
  3. Exact distanceΥπολογισμός L2 για κάθε candidate.
  4. Sort & Top-NSort, return top-N (protein_id, distance).

4 Extra: Silhouette Score

Υπολογισμός silhouette score (sample=100) για αξιολόγηση ποιότητας clustering:

for sample in sample_indices:
    a_i = mean distance από ίδιο cluster
    b_i = min mean distance από άλλα clusters
    silhouette = (b_i - a_i) / max(a_i, b_i)

IVF-PQ

Product Quantization + LUT — IVFPQ/ivfpq.py

1 Input

ΠαράμετροςΠεριγραφήDefault
--ivfpq_nlistIVF clusters100
--ivfpq_nprobeClusters προς εξέταση10
--ivfpq_mΑριθμός subspaces (πρέπει dim % m == 0)8
n_bitsBits ανά subspace (256 centroids)8

Για 320d embeddings και m=8: sub_dim = 40.

2 Build Phase

  1. IVF ClusteringKMeans(nlist) → ivf_centroids, ivf_labels.
  2. Inverted listsΑνάθεση κάθε vector στο cluster του.
  3. Residualsresidual = point - ivf_centroid[label].
  4. PQ TrainingΓια κάθε subspace m ∈ [0, M): KMeans σε 256 centroids → codebook[m]. Προσαρμογή cluster count ανά sub_dim.
  5. EncodingΓια κάθε point: για κάθε subspace: argmin_c ||subvector - codebook[m][c]|| → pq_code[i][m].

3 Query Phase

  1. Find nearest centroidsnprobe πλησιέστερα IVF centroids.
  2. Build LUTΓια κάθε subspace: LUT[m][c] = ||sub_query - codebook[m][c]||². Παράγει M × 256 entries.
  3. Distances μέσω LUTdist_sq += LUT[m][pq_code[point][m]]² — ΜΟΝΟ M προσθέσεις!
  4. Sort & Top-NSort κατά dist, return top-N.
최적화: Αντί για M × sub_dim = 8 × 40 = 320 υπολογισμούς, ο IVFPQ κάνει 8 προσθέσεις μέσω LUT.

4 Μετρικές

Ίδιες: Χρόνος, QPS, Recall@N.

Neural LSH

Learned indexing με MLP + k-NN graph — Neural/neural_lsh.py

1 Input

ΠαράμετροςΠεριγραφήDefault
--neural_kk για k-NN graph10
--neural_mΑριθμός partitions100
--neural_TTop-T bins (multi-probe)5
--neural_epochsEpochs εκπαίδευσης MLP10

2 Build Phase

  1. k-NN graphNearestNeighbors(n_neighbors=k+1) — για κάθε σημείο βρίσκουμε τους k κοντινότερους (αγνοώντας τον εαυτό).
  2. Adjacency listΔημιουργία adj = {i: [j1, j2, ...]}.
  3. PartitioningKMeans(n_clusters=m) → partition labels για κάθε σημείο. (Σημείωση: Εδώ χρησιμοποιείται KMeans αντί για KaHIP.)
  4. MLP trainingMLP(d → 256 → 256 → m). Εκπαίδευση με CrossEntropyLoss, Adam(lr=0.001), 80/20 split, batch=128.
  5. Inverted filedict {part_id: [indices]}.
  6. Save artifactsmodel.pth, inverted_file.pkl, partition.npy, ids.txt.

3 Query Phase

  1. MLP inferenceoutputs = model(query_tensor) → logits (m classes).
  2. Softmax + top-Tprobs = F.softmax(outputs); top_probs, top_parts = topk(probs, T).
  3. Union candidatesΣυλλογή όλων των indices από τα T partitions.
  4. Distance computationΔιανυσματικός υπολογισμός: np.linalg.norm(candidates - query, axis=1).
  5. Sort & Top-Nargsort, return top-N.

4 Μετρικές

Ίδιες: Χρόνος, QPS, Recall@N.

Υψηλό recall + μη ταυτισμένοι γείτονες = πιθανή λειτουργική σύνδεση (αυτοφαγία) που δεν φαίνεται στην ακολουθία.
Προσοχή: Μικρή L2 απόσταση δεν συνεπάγεται πάντα βιολογική σχέση — υπάρχουν false positives. Τα αποτελέσματα πρέπει να αξιολογούνται σε συνδυασμό με βιολογική πληροφορία (Pfam, GO, UniProt).

⚠️ Περιορισμοί & Βελτιώσεις

Περιορισμοί

  • Ποιότητα embeddingsΤο ESM-2 δεν είναι ειδικά εκπαιδευμένο για remote homolog detection.
  • Trade-off ταχύτητας-ακρίβειαςΠολύ υψηλό QPS (Hypercube) συνεπάγεται χαμηλό Recall.
  • BLAST ως ground truthΔεν ανιχνεύει όλες τις πραγματικές ομολογίες — το Recall υποεκτιμά.

Προτάσεις Βελτίωσης

  • Μεγαλύτερα ESM-2 variantsesm2_t33_650M ή esm2_t36_3B για καλύτερα embeddings.
  • Extra βιολογική πληροφορίαPfam domains, GO terms, PDB structures.
  • Συνδυασμός μεθόδωνΓρήγορο filtering με Hypercube + ακριβής ανάλυση με IVF-Flat.

5 Methods Compared

Η εργασία έδειξε ότι οι embedding-based μέθοδοι μπορούν να εντοπίσουν πιθανές ομολογίες που δεν ανιχνεύονται από το BLAST, ειδικά σε περιπτώσεις χαμηλής ομοιότητας ακολουθίας. Το Neural LSH παρουσίασε την πιο ισορροπημένη σχέση ταχύτητας-ακρίβειας, ενώ το IVF-PQ ήταν ιδιαίτερα αποδοτικό σε σενάρια όπου η ταχύτητα είναι κρίσιμη.

Συνολικά, ο συνδυασμός σύγχρονων protein language models και αποδοτικών μεθόδων ANN αποτελεί ένα χρήσιμο εργαλείο για τη μελέτη απομακρυσμένων ομόλογων πρωτεϊνών.
